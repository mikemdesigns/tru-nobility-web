# Tru Nobility wordmark directions

Both concepts use the approved complete crown without redrawing or altering its geometry.

## 01 — Heritage

Pairs the crown with American Brewery Rough and Archivo. This version is a review concept only. The available American Brewery font file does not include a verified production license, so confirm or purchase an appropriate commercial license before publishing this direction.

## 02 — Modern (recommended)

Pairs the crown with Source Serif 4 Semibold and Archivo Semibold. It feels editorial and contemporary while remaining connected to the site's established typography. Both typefaces are already included in the project under open-source licenses.

The current website header and footer implement the modern direction as live HTML and CSS. This keeps the name legible, responsive, and accessible while the crown remains the exact approved SVG asset.

The SVG files are editable source concepts. They reference the approved crown in `public/brand/` and expect the named fonts to be installed. The PNG files are rendered review proofs.
